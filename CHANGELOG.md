# Changelog

## 0.1.0 — initial release preparation

- Event drafts, scheduled publication, public voting links and downloadable QR codes.
- Owner, administrator and organizer accounts with explicit event assignments.
- Custom event content, covers, logos and color themes.
- Results dashboards with three-second polling, charts, CSV summaries and print/PDF reports.
- Cloudflare Pages, a private API Worker, KV event catalog and sharded SQLite Durable Objects.
- MIT license, contributor/security documentation and third-party notices.
- Local installation, isolated integration tests, CI and self-host deployment helpers.
- A clean source archive workflow that excludes credentials, production data and Git history.

The existing repository remains private during release preparation. No 50,000-user production capacity guarantee is made.
