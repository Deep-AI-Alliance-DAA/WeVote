WEVOTE / ADMIN

開一場投票，
即刻分享畀大家。

建立 event 後，就會有一條公開投票連結同 QR code。活動按你設定嘅時間自動開始、截止。

01 / 管理員登入

輸入管理密鑰

密鑰只會暫存喺呢個瀏覽器分頁；關閉分頁後要重新輸入。

管理控制台
01 / 新活動

建立投票 event

同一條公開 link／QR 可以畀所有人使用。選項建立後唔可以修改。

公開連結只可以盡量防重複：系統以瀏覽器識別同 Turnstile 驗證，但清除 cookie 或換裝置仍可能再投。正式結果如需「一人一票」，要改用每人獨立票據。

02 / 已建立活動

分享連結同 QR code

每個活動都有獨立連結。分享前請先開 link 檢查題目同時間。截止後可下載結果摘要、PDF 報告同逐票 CSV。
